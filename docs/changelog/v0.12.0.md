## movieclaw v0.12.0

这是一次覆盖媒体发现、媒体库首页、订阅管理和 AI 会话体验的集中升级。发现页现在支持
完整片单浏览与多条件筛选，媒体库首页加入按成员隔离的最近观看，订阅首页则更清楚地
展示今日更新、收录进度和预计入库时间；AI 对话也统一为可继续、可重试、可断线续传的
会话模型。

### 新功能

- **最近观看**：媒体库首页按成员展示最近播放的电影和剧集，保留观看进度、最近一集、
  新增集数和可见媒体库边界；同一剧集自动聚合为一张卡片
- **发现页高级筛选**：可按类型、产地、年份、评分、片长和排序方式组合筛选电影或剧集，
  筛选条件会写入 URL，方便刷新、返回和分享；榜单与片单支持完整分页浏览
- **更丰富的影视发现**：增加今日热榜、近期高口碑、年度新片、短片长、今日更新、
  本周更新和已完结迷你剧等入口；电影详情可直接浏览所属系列的全部作品
- **订阅首页总览**：剧集和电影分区展示并支持无感追加；新增今日更新列表、最近活动排序、
  自动续订标识和更紧凑的季/集收录摘要
- **统一 AI 会话**：Web 与 CLI 改用稳定的 session 入口，可继续已有会话、指定用户消息
  重新提问、停止处理或接回实时事件流；CLI 新增 `mclaw session` 工作流并支持断线续传

### 改进

- **预计入库更直观**：同日连续更新会合并显示，等待资源、下载中和整理中的状态文案统一；
  预计时间会结合站点礼貌间隔、历史耗时与实时 ETA，过期预测不再残留
- **媒体库大幅减负**：媒体数量、分集数、文件大小和异常项改为扫描及台账变更时预计算，
  列表和详情不再反复遍历全部库存；Jellyfin 目录统计同步复用同一快照
- **图片加载优化**：海报和横图按受控尺寸生成 WebP 派生缓存，共享并发去重和 LRU 清理，
  降低首页与移动端的图片传输和 NAS 编码压力
- **导航与任务入口**：详情页返回按钮优先恢复真实来路及筛选上下文；订阅等页面可直接深链
  到任务中心的进行中视图，实时任务标识和移动端信息层级更清晰
- **权限与数据边界**：最近观看、媒体库详情和相关发现投影统一遵守当前成员可见库范围，
  Agent、即时通信和 CLI 的内部访问继续收紧到各自需要的权限

### 修复

- 修复 SQLite 批量改表被异常中断后可能缺少媒体库分集统计列的问题；升级会按实际表结构
  补列并从有效库存重新回填，不覆盖其他统计快照
- 修复订阅海报墙长期按创建时间排列的问题；活动写入会原子推进排序时间，最新变化始终优先
- 修复应用会话详情路径可能被 Jellyfin `Sessions` 转发规则劫持的问题，并补齐旧 `/runs`
  页面到新会话入口的迁移
- 修复预测探测点与调度器礼貌间隔不一致、关闭自动续订后已选待播集缺少预测，以及全集包
  被错误当作单集发布时间样本等边界问题

### 升级说明

- 首次启动会新增媒体库统计快照、订阅最近活动时间及其索引/触发器，并执行一次分集统计
  完整性修复；迁移只向前增加或修正数据，应用更新前仍会自动备份
- 本版本未改变 Python/Node 运行时依赖、Docker 基础镜像或入口契约，runtime 版本保持 7；
  现有 runtime 7 用户可直接使用应用内更新，也可以拉取 v0.12.0 镜像整体升级
- 若需要跨版本回退，请使用更新前自动备份恢复数据库，避免旧版本读取新迁移后的结构
