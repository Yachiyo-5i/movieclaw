## movieclaw v0.9.0

这是一次围绕字幕、多成员和 Jellyfin 客户端体验的大版本更新：可以从现有字幕
生成 AI 外挂字幕、识别 PGS 图形字幕，种子识别模型也升级到 v2，并新增按字幕与
音轨语言选种；同时补齐多成员权限隔离、Infuse 接入和手动下载智能入库。

> **本版本必须更新 Docker 镜像。** 运行时从 3 升级到 5，新增字幕解析依赖、
> Subtitle Edit 转换器、Tesseract OCR 与多语言包。旧镜像不能承载本版本的
> PGS 字幕能力，也无法通过应用内更新安装 v0.9.0。Docker Compose 用户可执行
> `docker compose pull && docker compose up -d` 更新；新镜像同时内置
> `torrent-ner-v2`。

### 新功能

- **AI 外挂字幕生成**：从现有内封或外挂字幕中自动选择最佳来源，用已配置的
  LLM 生成单语或双语字幕；支持术语表、分块并发、滚动上下文、质量机检、
  进度展示、停止与断点续传。任务完成后直接落成视频同目录的标准 sidecar
  文件，Jellyfin、Infuse 和其他播放器都能继续使用
- **字幕时间轴校准与预览**：生成前会检查字幕同步情况，可按音轨真相源校准
  全局偏移和帧率差；媒体详情页可预览字幕内容，也能对已有外挂字幕单独发起校准
- **PGS 图形字幕识别**：Docker 镜像内置跨架构 Subtitle Edit 转换器与
  Tesseract OCR，支持从 PGS 抽帧、识别并生成 SRT；能力预检和镜像构建烟测会
  阻止缺少动态库、字体或语言包的坏镜像发布
- **字幕完整消费链路**：媒体库会登记外挂字幕，识别中文常见命名与编码，
  提供 SRT/VTT 转换和 Jellyfin 字幕流接口；每位成员的音轨、字幕轨选择会分别记忆
- **种子识别模型 v2**：基于 17 个站点、26,432 条语料重新训练，新增字幕声明与
  音轨声明识别。搜索结果会显示字幕/音轨标签，规则组可要求中文字幕、简体中文、
  国语、粤语等语言；未声明相应语言的资源不会被自动选中
- **多成员账号与权限**：管理员可创建成员，并分别控制可见媒体库、可搜索站点和
  一键下载权限。搜索历史、界面偏好、播放进度、收藏与字幕选择按成员隔离；
  订阅支持发起人和关注者语义，Jellyfin 客户端也会投影为独立用户
- **手动下载智能入库**：搜索结果下载前可按媒体库规则预判目标，投递时记录
  infohash 身份锚；下载完成后监听入库能沿用已确认的作品身份和目标媒体库，
  减少手动选路径与二次识别

### 改进

- **Infuse / Jellyfin 兼容增强**：补齐 Infuse 添加媒体库所需的 Plugins、
  VirtualFolders、GroupingOptions 与 DisplayPreferences 接口，前端端口也能完成
  探测；成员客户端只会看到获准的媒体库，直达详情、播放和下载同样受权限约束
- **本地元数据优先**：Web 与 Jellyfin 共用本地 NFO、图片和媒体信息的分层读法，
  写入时保留资产来源，单条目详情可自愈缺失元数据；扫描和刷新元数据增加二次确认，
  媒体库卡片可直接发起刷新
- **界面细节**：优化媒体库与订阅空状态；站点名称和头像可直接打开站点；修复
  移动端启动接口失败时白屏、旧版 WebKit 媒体查询兼容、海报延迟解码导致 hover
  信息不出现等问题
- **下载健壮性**：智能路由参数改为显式校验，自动清理长期未消费的下载身份锚，
  数据库迁移链保持单一 head

### 升级说明

- 请先更新 Docker 镜像，再使用 v0.9.0；仅做应用内更新会因为 runtime 不匹配
  被安全拒绝
- 新镜像已内置 `torrent-ner-v2`。现有部署也可先在「设置 → 应用」单独安装
  模型更新；模型 v2 的字幕/音轨字段会在 v0.9.0 中被完整消费
- 提取版本升级到 ENRICH_VERSION 15，首次启动会自动重算存量种子属性，期间
  搜索筛选和自动选种结果会逐步刷新
- 数据库迁移只新增成员、字幕台账和手动下载意图等向前兼容结构；升级前仍会按
  既有机制自动备份，跨版本回退时使用对应备份恢复数据
