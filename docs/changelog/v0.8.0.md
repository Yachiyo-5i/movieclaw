## movieclaw v0.8.0

一批社区与日常使用驱动的更新：识别错挂终于可以手动修正，搜索能按
简体中文字幕筛选，新增 AGSVPT 站点，HDR 与杜比视界可以分开控制，
极空间用户的硬链接落位问题也修好了。

本版本**不需要更新 Docker 镜像**（runtime 仍为 3），在「设置 → 应用」
一键更新即可。

### 新增

- **识别错挂可以手动修正了**：此前机器高置信认错片时，界面上没有任何
  改挂入口，「重新识别」大概率复现同一个错答案。现在影片详情页提供
  「修正识别结果」面板：先只读地重跑一遍识别看结论，可以采纳、也可以
  自己搜索一个正确条目认领（认领前会展示海报简介确认），还可以把花絮、
  预告片这类内容标为「非独立作品」移出影片库。改挂后旧条目自动清理
- **花絮不再冒充影片**：正片旁边的 trailer / 花絮曾会拿自己的文件名去
  搜 TMDB 而被识别成别的电影。现在电影按「Title (Year)」条目目录名
  优先取证，并按 Emby/Jellyfin 的 extras 目录惯例（含中文常见叫法）
  与 `-trailer` 类文件名后缀忽略花絮。存量库中的错挂会进入「身份复核」
  清单，由你逐个拍板，不会擅自改动
- **搜索结果可按简体中文字幕筛选**：从种子标题与描述中识别简中字幕
  （简中、简繁、简英双语、简日/简韩等写法均覆盖），搜索结果新增筛选
  开关。发布时同步修复了「配音：简中」「无字幕组水印」等一批误报/漏报，
  存量数据会在下次启动后自动重算
- **HDR 与杜比视界拆成两个独立的过滤维度**：2160p 资源大量是 HDR.DV
  双标，设备不支持 DV 的用户此前无法只要 HDR 不要 DV。现在订阅规则里
  HDR 与 DV 各自可设「不限 / 必须 / 排除」，例如「必须 HDR 但排除 DV」
  = HDR:必须 + DV:排除。既有规则组的语义完全不变，无需调整
- **新增 AGSVPT 站点支持**：在「设置 → 站点」按声明式配置接入
- **发现页显示「已在库中」标识**：浏览推荐、榜单时能直接看出哪些
  影片已经入库，并可点击跳转到库内详情

### 修复

- **极空间「极影视」识别不到入库的文件**（#103）：极空间的文件系统
  只对 create/rename 这类操作产生媒体索引事件，硬链接落位的文件在
  极影视里永远"不存在"。现在所有落位（硬链、复制、整理改名）统一
  改为「先备好内容、再 rename 发布」，极影视可以正常收录；防覆盖
  语义不变，其他 NAS 用户无感知
- **M-Team 成人分类搜索不到结果**：H 类目现在正确路由到成人索引
- **监听导入的「已入库」改为按作品计数**：一部剧的多季、同一部片的
  多个版本此前会被各计一次（实测 4 部剧显示「已入库 11」）。现在按
  识别到的作品去重计数，条目数与文件数在明细中依然可见；历史数据
  自动回填合并

### 说明

- 数据库迁移向前兼容（仅新增台账字段，不改动已有数据），应用内更新
  支持一键回退（跨版本回退由更新前的自动备份兜底）
- 识别器与数据提取版本升级（RESOLVER_VERSION 5、ENRICH_VERSION 13）
  会在更新后触发存量数据的自动重算与身份复核提示，属预期行为
