## movieclaw v0.10.0

这是一次围绕后台任务可靠性与可观察性的完整升级：新增统一任务中心，把字幕生成、
媒体库扫描、元数据刷新、整理、转移和监听入库收敛到可持久化作业系统，并汇总下载器
与订阅下载状态。任务不再依赖单个进程内的临时协程，服务重启或应用更新后会按租约和
检查点继续执行或安全重试。

> **本版本必须更新 Docker 镜像。** 运行时从 5 升级到 7，容器启动、前后端监督与
> 自愈契约已更新。旧镜像无法承载 v0.10.0 的完整启动与恢复机制，也会被应用内更新的
> runtime 校验安全拒绝。Docker Compose 用户可执行
> `docker compose pull && docker compose up -d` 更新。

### 新功能

- **统一任务中心**：侧边栏可直接进入完整页面，集中查看后台作业、下载与入库；历史
  结果归入对应类型，不再单独拆分。页面通过事件流自动刷新，并以轮询作为断线兜底
- **可恢复后台作业**：字幕生成、媒体库扫描、单条目与整库元数据刷新、文件整理、
  条目转移和监听入库统一使用持久作业。作业带稳定 ID、资源锁、租约、检查点、取消、
  重试和审计来源，更新或异常重启后不会因为进程退出而静默丢失
- **下载与入库汇总**：统一读取 qBittorrent、Transmission、订阅下载与手动下载线索，
  展示下载、做种、等待入库和已入库状态；识别到影片或剧集时显示海报，同一剧集的任务
  合并展示
- **结构化任务明细**：字幕任务展示目标语言、阶段、请求数、输入/输出 Token、输入缓存
  与耗时；媒体库任务展示真实处理阶段和结果摘要，已完成任务不再保留无意义进度条
- **蓝光原盘语言识别**：扫描 BDMV 时读取 CLPI 流信息，为 ffprobe 缺失的音轨语言补齐
  元数据，损坏或缺失的 CLPI 会安全降级
- **北洋园账号登录**：TJUPT 新增用户名与密码登录方式，同时保留既有 Cookie 配置路径

### 改进

- **任务中心界面重设计**：采用分层任务卡片、对象标题与动态动作句；任务类型、来源、
  时间等稳定信息使用统一胶囊展示。移动端以状态圆点替代长状态文字，减少拥挤
- **根路径变更安全对账**：媒体库根路径改为挂载别名或软链接时，通过 inode 与受限指纹
  延续原台账，避免同一文件重复入库；已有重复行会在身份一致时收敛，并同步迁移关联的
  持久作业历史和重试输入
- **容器启动与自愈增强**：增加启动占位页、依赖监督、前端重启轮询和可读诊断；后端以
  特定退出码请求单独重启时无需重启整个容器，自愈事件可在应用内查看
- **扫描与字幕可靠性**：扫描作业按资源锁与安全边界取消，字幕翻译用量和断点持续落盘；
  根路径变更、台账合并与任务恢复之间保持一致，不会让任务继续指向已删除记录

### 升级说明

- 请先拉取 runtime 7 的新 Docker 镜像，再升级应用到 v0.10.0；仅在旧镜像内执行应用
  更新会被兼容性检查拒绝
- 首次启动会新增 `job`、`job_resource`、`job_event` 与 `job_lock` 等持久作业表，并补齐
  作业对象、版本追踪和资源消耗字段；迁移只新增结构，保持向前兼容
- 更新前仍会按既有机制自动备份。升级过程中正在执行的统一作业会在新进程取得租约后
  继续或安全重试；若跨版本回退，请使用对应的更新前备份恢复数据库
