## movieclaw v0.14.0

这是一个大版本更新，带来两条全新的自动化链路：**洗版**让库里的旧资源自动升级到更好的
版本，**站点保护与自动刷分享率**替你守住 PT 站点的分享率红线。任务中心、订阅调度和
发现页也随之做了一轮打磨。

### 新功能

- **洗版（自动 + 手动）**：为已入库的电影和剧集寻找更高画质、更优片源的替换版本，
  自动完成下载、替换与旧文件回收；也可以在详情页手动挑选目标版本。配套带来媒体库
  文件回收机制、原盘多版本摆放规范，以及「无法确认档位」时的片源人工标注入口
- **站点保护与自动刷分享率**：站点可开启保护开关，分享率逼近红线时自动抢免费种刷流
  拉升；汰换策略按完成时刻分层判定、优先采用站点真实 H&R 考核时长，调小预算会硬性
  收敛到位，配合下载器限速与队列管理，不影响正常下载
- **预告片**：发现页详情新增预告片展示与内嵌播放
- **电影上映感知调度**：未上映/刚上映的订阅不再反复白搜，按上映节奏安排搜索；订阅
  首页预告支持回看一周内已上映的内容
- **按分类浏览种子**：站点搜索关键词留空时，直接按分类浏览各站最新种子列表

### 改进

- **任务中心**：种子行重排——补齐站点与规格信息、去掉重复状态；剧集任务按逐集工单
  展示入库进度；洗版任务按「替换了几集」讲进度，「等待入库」换成真实步骤链；系统
  取消的任务讲清原因，被取代的批次不再提供「重新执行」；sidebar 角标不再计入刷流
  任务，数字回归提醒本义
- **订阅海报**：洗版数量以「洗 N」徽标外显，位置与配色多轮打磨保证可读；季集摘要
  措辞对齐媒体库语义；追更中的订阅同样能看到洗版进度
- **发现页**：「已入库」统一为海报左上角绿斜标；最近观看卡片重排角标与进度，观看
  角标改为「未看 N 集」，看完与洗版中不再误报
- **站点管理**：刷流操作改为菜单化确认，站点显示 favicon 与动态副标题；账号被停用
  等认证类失败快速熔断并透传站点返回的真实原因，重新验证成功后立即清除旧失败文案
  与退避排期
- **种子识别**：单集文件名盲区定向增强，扫季启用确定性门禁（配合 torrent-ner-v3
  模型）；字幕识别的否定护栏按审计结论退役，减少误伤
- **构建与弱网体验**：界面字体改为本地自托管，不再向 Google Fonts 发起外联请求

### 修复

- 修复 qBittorrent 4.4.0 以下版本保存全局限速/队列设置时误报「无法连接到
  qBittorrent」、且队列参数写不进去的问题
- 修复洗版链路的一批入库缺陷：显式季集解析、冲突分级、同档去重与来源戳；显式 E00
  按先导/特辑占位跳过；整包同档跳过后也做库存对账并关闭已满足的工单；整树入库成功
  后收口被取代的分批挂起作业
- 修复订阅两类卡死：孤儿在途工单补跑完成核验，虚标缺集不再永久挂起；内容核验发现
  缺集时写入负面记忆，终结「退回→重抓同一种子」死循环；种子完成但缺承诺集数时退回
  重找，全集包不再承诺特别篇
- 修复回收站对做种保护的过度猜测——一律按保留期倒计时自动清理
- 修复 M-Team 积分商城「单种免费」生效期间未按全免费计费的问题
- 修复分批入库的批次连坐——挂起批次不再拖累同条目剩余集；补齐升级补偿的缺口并防止
  中转/批次场景的错误重跑
- 修复 Docker 看门狗变量名被中文标点吞掉、启动占位页被反向 DNS 拖住的问题
- 修复媒体库「最近添加」在触摸端无法展开信息层的问题

### 升级说明

- 首次启动会执行数据库迁移，为刷流汰换、H&R 考核等新增字段；迁移向前兼容，应用内
  更新前仍会自动备份数据库，跨版本回退请用该备份恢复
- 种子识别建议配合最新 NER 模型：设置页 → 模型更新到 `torrent-ner-v3`
- 本版本未改变 Python/Node 运行时依赖、Docker 基础镜像或入口契约，runtime 版本保持
  7；现有 runtime 7 用户可直接使用应用内一键更新，无需重拉镜像
