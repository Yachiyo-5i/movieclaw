## movieclaw v0.13.0

这次更新继续打磨媒体发现与媒体库浏览体验。发现页的演职员现在可以进入完整影人作品页，
媒体库首页能准确说明一批新入库的剧集范围；影视详情、文件信息、海报操作与字母索引也统一
了信息层级，让找片、看库存和判断文件质量更直接。

### 新功能

- **发现页影人作品页**：从电影或剧集详情点击演员、导演后，可浏览该影人在 TMDB 的完整
  影视履历；作品会标明已入库或已订阅状态，并可继续打开详情和发起订阅
- **最近入库批次**：剧集入库会记录本轮批次，媒体库首页据此显示本次新增的季、集数或连续
  集号，不再把整部剧的累计库存误当作刚刚添加的内容
- **文件视频参数**：媒体文件详情新增帧率和色彩空间，配合分辨率、HDR、编码与码率展示；
  多版本影片和分集可以切换物理文件，查看对应音轨、字幕及视频信息

### 改进

- **影视详情统一**：发现详情与媒体库详情采用一致的元信息、简介、演职员和外部链接层级；
  简介仅在真实溢出时显示展开入口，导演与演员合并为可横向浏览的人物列表
- **媒体库海报墙**：字母索引会随真实滚动位置更新并保留恢复后的活动字母；库存卡片更准确
  地展示全季、全集与缺口，并根据当前库存提供补齐或自动续订入口
- **最近添加更清爽**：海报正文只保留片名和年份，新增集数与入库时间移入悬停信息；订阅、
  补齐等操作留在单库页面，避免首页卡片信息过载
- **音轨与字幕信息**：音轨、字幕徽标改为紧凑标签，完整语言、编码、声道、内封/外挂与轨道
  信息通过详情或提示展示；AI 字幕状态也使用一致的视觉语义
- **画质与时长文案**：统一电影、剧集和文件的时长格式，并修正消费级分辨率命名，避免把
  1080p 标成 2K；色彩空间与 HDR 标签优先展示更明确的格式
- **库存关系更准确**：发现结果只按可靠的外部 ID 和仍存在的物理文件判断“已入库”；详情
  链接和相关作品保持稳定排序，豆瓣人物与作品数据的容错继续增强

### 修复

- 修复最近添加只能显示条目累计季集数、无法区分本轮新增内容的问题；旧库存没有批次号时
  会安全退回入库时间展示
- 修复手动安装或恢复 ffprobe 后，历史媒体文件缺少视频参数且无法补齐的问题；主动整库扫描
  会幂等回填帧率、色彩空间等信息，后台轻量对账不会反复探测
- 修复媒体库字母索引在恢复滚动位置或跨字母分区后高亮不准确，以及部分海报已订阅时仍显示
  重复订阅/补齐操作的问题

### 升级说明

- 首次启动会为媒体文件新增可空的入库批次、帧率和色彩空间字段；历史行保持兼容，旧版本
  回退后也能继续写入，应用更新前仍会自动备份数据库
- 历史视频参数不会在启动迁移时扫描文件；需要补齐时执行一次主动整库扫描即可，缺少 ffprobe
  或 `.strm`、缺失、忽略文件会安全跳过
- 本版本未改变 Python/Node 运行时依赖、Docker 基础镜像或入口契约，runtime 版本保持 7；
  现有 runtime 7 用户可直接使用应用内更新，也可以拉取 v0.13.0 镜像整体升级
- 若需要跨版本回退，请使用更新前自动备份恢复数据库，避免旧版本读取新迁移后的结构
